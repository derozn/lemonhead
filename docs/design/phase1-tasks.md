# Phase 1 Task Breakdown

Each task is one reviewable increment (one PR), lands green on CI, and states its own verification. Order matters; later tasks depend on earlier ones. Estimates are relative size, not hours.

All blocking decisions were resolved with the owner on 2026-08-05 (spec §11.2–11.9): England-only, month-aware 12-month horizon, full UC modelling for current claimants, full-schedule manual entry, localStorage-only with memory-only financial figures, multi-child schema.
